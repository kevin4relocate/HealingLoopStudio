# Healing Loop Studio — AI photo animation (v2)

Cloudflare Pages website for generating short, looping meditation visuals from an **AI-generated still image** and periodic glow / particle effects. The human and background remain fixed in the original artwork.

## How to use

1. Download your AI-generated PNG/JPEG/WebP image from ChatGPT (for example, `sleeping_among_the_stars.png`).
2. Open the Cloudflare website and click **AI background library → Choose Files**.
3. Select the photo. A preview should immediately show your real artwork with slowly moving light effects.
4. Press **Generate random 10s video**. If several photos are uploaded, the app can choose randomly among them. The file picker is used only once; photos are stored locally in the browser via IndexedDB.
5. Download an MP4 (if the browser has H.264 WebCodecs support) or a WebM fallback.

No AI APIs, video rendering server, or paid subscriptions are needed.

## Deploy to Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Output directory: `dist`

## Development

Run `python3 -m http.server 8787`, then open http://localhost:8787.

## Important limitations

- Cloudflare Pages hosts the code; video encoding runs locally inside the browser.
- A photo **must be selected at least once**. Without an uploaded photo, the app displays an upload prompt, not a low-quality procedural human.
- Photos are stored in your local browser storage, not in GitHub or Cloudflare. If local browser storage is cleared, upload them again. Different browsers and devices have different libraries.
- The still image is not generated by AI inside the website. Randomization changes chosen saved image, lighting style and particle trajectories.
- Motion is mathematically 10s-periodic. The exact-frame MP4 export samples frames at 0, 1/30, ..., 299/30 seconds. There is no duplicate 10s endpoint frame. MP4 encoder or player settings can still affect visual seams, so validate by placing two exports back-to-back in a video editor. WebM fallback is real-time and not frame-accurate.
